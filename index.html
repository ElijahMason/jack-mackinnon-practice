The desk is part of the system.

Jack MacKinnon is a software engineering contractor. He works the physical layer upstream of the software: office workflow, cable management, monitors, lighting, desks, and custom workspace engineering. He builds and installs the room, and he writes the software for the same teams.

You bring him a team whose program and furniture disagree. A screen the software expects is missing. A cable has no name. The desk cannot be cleared. He sets the room and the code so they describe the same place.

A cable you can trace. A desk you can clear. Software that assumes the room was designed. Label both ends.

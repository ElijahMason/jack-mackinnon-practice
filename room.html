Draw the route before you pull it.

The room is a layout before it is a look. Jack MacKinnon sets the bench, the mounts, the light, and the cable routes, then matches the office workflow to that layout. The desk is part of the system.

Layout

Put the daily work on the top. Give everything else a path off it. A layout is a route for a person, a panel, and a pile. A pile with no route stays, and the desk stops clearing.

Mounts

An arm holds the panel inside the edge of the desk. Swing it through the travel you actually use before you load the tray. A panel that leaves the edge snags a sleeve and throws glare across the room. The tray under the panel carries the power brick and the short leads so the top can stay clear.

Lighting

Light the task. One pool lands on the work. Keep it out of the eyes, and keep it from washing the whole panel. Ceiling light is for the room. The lamp is for the page, the keyboard, and the label you still have to read.

Cable routes

Draw the route, then pull the cable. Separate power and signal where the run allows. Leave enough slack to service the arm, and no loop that becomes a snare. Every run gets a name. Both ends carry that name.

Office workflow

A request needs a place on the desk, a path through the software, and a way back to a person as something they can file or hand on. Jack sets that path in the furniture and in the code. If the path needs a pile, the path is wrong.

Two ends, one name.

Registration is how a press checks that every plate hits the same point. Jack MacKinnon uses the same check on a cable. The desk is part of the system.

If the plates miss, the picture fringes. If the labels miss, you cannot trace the run. Label both ends before the cable lands. The name at the port is the name at the device.

The software uses that name. It does not invent a second one. You should be able to read the tag, then find the same word on the screen.

A desk you can clear still needs names you can follow. Trace first, then tidy.
